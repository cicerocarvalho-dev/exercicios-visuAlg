# Calculadora de Empréstimo em VisuAlg

## Sobre o projeto
Meu primeiro exercício de lógica de programação desenvolvido no VisuAlg.

## Objetivo
Calcular o valor das parcelas de um empréstimo considerando uma taxa fixa de 20% de juros sobre o valor inicial.

## Conceitos praticados
- Variáveis
- Tipos de dados: inteiro e real
- Entrada de dados (leia)
- Saída de dados (escreva)
- Operações matemáticas
- Cálculo de porcentagem
- Divisão de parcelas

## Exemplo
Empréstimo: R$ 1.000,00

Juros: 20%

Quantidade de parcelas: 10

Resultado: 10 parcelas de R$ 120,00.
